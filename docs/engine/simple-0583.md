# MSG0583 간편 후보 계약

기존 WO와 Draft PR17의 후속이다. 공통 변경의 PR18/main 게시 승인과 이 후보의 승인 범위를 구분한다. 공통 main `720ad6e3f83b11b331754eadd114b9ce7c1b62ca`를 정상 병합한 뒤 후보를 수정했다. 이 문서는 시험 결과나 사용자 수락 선언이 아니다.

## 소유자와 저장 경계

| 영역 | 실제 소유자 | 경계 |
| --- | --- | --- |
| Q1·알려진 Q2 | app, quantity-contract, numeric-input, q2-cost | 기존 규격·낱개 수요·가격 의미와 공통 counter 유지 |
| 미확인 Q2 | simple-quote-contract, app | unknownMonthly의 qty/unit/budget 원자료; 기존 price와 분리 |
| 지역 참조 | region-reference | 고정 정부 코드 자료; 배송·사업자·상세주소 검증 아님 |
| 지역 입력 | simple-region-ui, simple-quote-ui | 검색어·IME·하이라이트는 로컬; 명시적 완전 선택만 부모에 전달 |
| Q4 | simple-quote-ui, date-field, q4-date | 본문 inline; 기존 주문 값·달력 사용 |
| 지속 저장 | storage | 기존 후보 키, revision·transaction·충돌·초기화 계약 |

Q1의 모름 선택은 선택 상태와 상담 관심 체크박스를 보여준다. 그 자체로 Q2에 이동하지 않는다. 현재 명시적 체크 의도의 성공한 저장만 자동 이동할 수 있다. 복원·기존 체크·해제·실패·오래된 응답은 이동 권한이 아니다. 편집 팝업에서는 확인 전 private 초안이며 취소는 원본을 바꾸지 않는다.

알려진 규격의 수량·단가는 모름 전환 뒤에도 잠재 원본으로 남는다. 모름의 `unknownMonthly:{qty,unit,budget}`를 이 값들과 복사하거나 포장수로 환산하지 않는다. 모름 입력의 단위는 개/판/팩 원자료이며 확인되지 않은 30구를 가정하지 않는다. 고객 월예산은 선택 입력이라는 **작업 가정**이다. 예산은 현재 월 구매비용·절감액·포장단가가 아니다. 실제 요청 projection도 숨겨진 known 가격을 차단한다.

사업장 수는 새 입력에서 1로 시작하고 확정 범위는 기존 최대 500을 유지한 1..500이다. 일시적인 빈 문자열은 로컬 초안이다. count의 입력 접두값만으로 사업장을 삭제하지 않으며 확정 때 stable ID/지역을 처리한다. 공통/개별 지역 모드 전환은 다른 모드 원본을 지우지 않는다.

## 지역 원자료

`code.go.kr` 공개 법정동 전체 파일의 `존재` 행에서 시·도와 terminal 시·군·구만 추출했다. 두 번째 필드는 `수원시 영통구` 같은 복합 이름, 군, 제주시를 그대로 표현한다. 세종은 실제 코드 `3611000000`으로 직접 선택하며 없는 구를 요구하지 않는다. 원자료의 버전·수집시각·ZIP 및 본문 해시는 모듈의 provenance와 납품 원본에 보존한다. 자료 갱신은 별도 원본 비교와 검사를 거친 변경이며, 이 후보는 자동 갱신이나 배송권역 정책을 만들지 않는다.

예전 자유입력 문자열은 코드로 추측하지 않는다. 새 선택값은 `referenceVersion/rootCode/leafCode/rootLabel/leafLabel`이며 검색어, 부분 선택, 해당 목록에 없는 값과 구분한다. 카탈로그 선택을 실제 주소 제공자 응답으로 승격하지 않는다.

현재 후보 계약 식별자는 `provisional-0583-1`이며, 이전 `provisional-0581-1`의 두 번째 계약 세대다.

## 버전과 이관

| 입력 | 읽기 | 다음 성공한 명시적 저장 |
| --- | --- | --- |
| schema9 / provisional-0581-1 | 기존 strict decoder, 원본과 쓰기 0 유지 | v2/schema10으로 투영 |
| 유효한 옛 count 1..500 | 값·ID·지역 원본 유지 | confirmed 상태로 유지 |
| 옛 빈값/0/범위 밖 count | 정확한 legacySiteCount 보관, 화면 기본 1과 미확인 구분 | 사용자의 count 완료 후에만 확인 |
| 옛 raw 지역 | 원문 유지, 새 공식 선택으로 자동 승격하지 않음 | 명시적 지역 선택만 새 선택값 |
| schema10 | strict v2 필드 검사 | 같은 writer와 revision 사용 |

상세 제품 저장 키·옛 상세 session을 간편 후보로 이관하지 않는다. 읽기/렌더는 저장 성공이 아니며, 실패나 revision 충돌 시 다른 탭 값을 덮어쓰거나 자동 병합하지 않는다.

## 남은 경계

월 범위의 상용 의미, 실제 공급가·공급처 표시 시점, 인증/사업자 확인, 공급권역과 주문 접수는 확정되지 않았다. 모름의 선택 단위 환산과 월예산 필수성도 임의 확정하지 않는다. CI의 합성 데이터/브라우저 검사는 실제 제공자·사용자 OS·디자인 최종 수락을 대신하지 않는다. 최종 실행 로그와 동일 SHA CI, 저장 경계 및 LAB은 별도 납품 보고서에서 연결한다.
